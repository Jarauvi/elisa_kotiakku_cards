## 🚀 Installation

### Option 1: HACS (Recommended)
1. Open **HACS** > **Integrations**.
2. Click the three dots in the top right and select **Custom Repositories**.
3. Paste: `https://github.com/Jarauvi/elisa_kotiakku_cards`
4. Select category **Dashboard** and click **Add**.
5. Reload Home Assistant user interface.

### Option 2: Manual
1. Download the `elisa_kotiakku_cards.js` from this repo`.
2. Copy it to your Home Assistant `config/www/community/elisa_kotiakku_cards` directory.
3. Go to Settings -> Dashboards -> Add resources (top right corner)
4. Add resource `hacsfiles/elisa_kotiakku_cards/elisa_kotiakku_cards.js`
